# 使用
1. 下载模组，并解压，得到 `HvrChinese.dll` 等文件
1. 从 [BepInEx](https://github.com/BepInEx/BepInEx/releases) 下载 BepInEx 6
1. 把 BepInEx 解压到 Holo vs Robo 安装目录
1. 把模组文件复制到 `游戏目录/BepInEx/plugins/HvrChinese/` 即可。
